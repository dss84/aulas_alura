# Portfolio Diego Sirtoli

Este é um projeto de portfólio pessoal desenvolvido em HTML e CSS, com o objetivo de apresentar informações profissionais, redes sociais e um pouco sobre mim.

## Features

- **Página inicial (Home):**
  - Apresentação pessoal com nome, especialidade e breve descrição.
  - Links para redes sociais (GitHub, LinkedIn, Twitch) com ícones personalizados.
  - Layout responsivo para diferentes tamanhos de tela.
  - Destaque visual para frases importantes.

- **Página Sobre Mim:**
  - Seção dedicada a informações adicionais sobre o autor.
  - Imagem ilustrativa e textos descritivos.

- **Design e Estilo:**
  - Utilização de variáveis CSS para cores e fontes.
  - Fontes personalizadas importadas do Google Fonts.
  - Efeitos de hover nos botões de navegação.
  - Imagens com bordas arredondadas e sombra.
  - Rodapé personalizado.

- **Responsividade:**
  - Layout adaptável para dispositivos móveis e desktops.
  - Ajustes automáticos de espaçamento, tamanhos de fonte e imagens.

## Estrutura de Pastas

Basta abrir o arquivo `index.html` em seu navegador preferido.
